# Windows 日用验收剧本（M01 + 平台项）

> 目标：在干净 Windows 10/11 x64 上，不依赖开发者机器配置，把 Grok App 跑到「能开项目写一轮工具对话」。  
> 对应能力：K03 / K04 / D06 / C01–C04 / G01–G05 / M01。

## 前置

- Windows 10 22H2+ 或 Windows 11，x64
- 可访问 GitHub Releases（下载 App / CLI）
- 可选：已有 xAI 账号或自备 OpenAI 兼容中转

## 安装

1. 从 [Releases](https://github.com/RongleCat/grok-app/releases) 下载最新 `*-setup.exe`（或产品当前 Windows 产物名）。
2. 若 SmartScreen 提示「未知发布者」：
   - **更多信息** → **仍要运行**（社区签名前的预期行为，见 README）。
3. 完成安装并启动 Grok App。

## 剧本 A — 新机器日用（M01）

| 步骤 | 操作 | 期望 |
|------|------|------|
| A1 | 冷启动 App | ≤ 数秒进入壳；无崩溃 |
| A2 | Setup / Doctor 检测 CLI | 未安装时有引导；可确认后下载 |
| A3 | 三入口之一完成鉴权（官方 / 中转 / 导入） | 密钥不明文；连通测试成功或明确失败原因 |
| A4 | 添加本地项目（路径含空格，如 `C:\Users\…\My Project`） | 信任确认后可进入 |
| A5 | 新建会话，发送「列出当前目录文件」 | 流式输出；工具步骤可见；可 Stop |
| A6 | 写文件/跑命令类请求 | 默认 Ask 权限条；Allow once / session / Deny 可用 |
| A7 | 设置 → 关于 → 检查更新 | 能显示当前/最新版本；可打开发布页或下载安装包 |

## 剧本 B — 路径与壳

| 步骤 | 操作 | 期望 |
|------|------|------|
| B1 | 项目路径含空格、盘符 `D:\` | 会话 cwd 正确，工具不因路径失败 |
| B2 | 无边框窗控：最小化 / 最大化 / 关闭 | 可点；关闭行为符合「退出 / 托盘」设置 |
| B3 | 亮色 / 暗色切换 | 设置页与对话区无漏主题 |

## 剧本 C — 失败可区分

人为制造四类失败，确认文案不互相冒充：

1. **CLI 未找到**：设置错误 CLI 路径 → Doctor / 对话提示装 CLI，不是「鉴权失败」  
2. **鉴权失败**：错误 API Key → 指向账户/提供商  
3. **网络/中转**：断网或错误 base_url → 网络/提供商类 deck  
4. **Agent 崩溃**：杀 `grok` 子进程 → 可重新附着，不是「CLI 未找到」

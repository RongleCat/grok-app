# 多语言（i18n）规则

**强制**：用户可见的 UI 文字禁止硬编码中英文。一律走 `t(locale, key)` / `createT(locale)`。

当前语言：`en` / `zh`（简体）/ `zh-TW`（繁体・台湾）。三者键集合必须一致（由 `Record<Locale, …>` 类型与 messages.test.ts 强制）。

## 源码位置

| 路径 | 职责 |
|------|------|
| `src/i18n/messages.ts` | 文案目录：`en` 为键权威源，`zh`（简体）必须同键齐全 |
| `src/i18n/zh-tw.ts` | 繁体中文（台湾用语）目录，键与 `en` 齐全 |
| `src/i18n/index.ts` | `t` / `createT` / `resolveLocale` / 类型导出 |
| `src/App.tsx` 等 | 只引用 key，不写死 `"设置"` / `"Settings"` |
| `src-tauri/src/tray_i18n.rs` | 系统托盘 / 状态栏菜单文案（与 `tray.*` 键同步；读 `settings.locale`） |

## 新增或修改文案

1. 在 `messages.ts` 的 **`en` 对象** 增加键（snake 或点分：`area.action`）。  
2. **同一 PR** 在 `zh` 写完整中文（人工或 AI 翻译均可，但必须语义完整、产品语气一致）。  
3. 组件内：`const tr = useMemo(() => createT(locale), [locale]);` 后使用 `tr("sidebar.settings")`。  
4. 带变量：模板用 `{name}`，调用 `tr("project.trustFirst", { name: proj.name })`。  
5. **禁止** `locale === "zh" ? "…" : "…"` 再扩散；存量替换时删掉三元。  
6. 产品名 / 模型 ID（如 `Grok 4.5`、`Agent`）可保持英文品牌名；说明性文案必须双语。  
7. 设置里切换语言后写入 `settings.locale` 并即时 `setLocale`。

## 翻译质量

- 中文：简体、完整句、与桌面产品语气一致（克制、直接）。  
- 英文：完整句子、Title Case 仅用于短按钮/导航。  
- 占位符 `{name}` `{path}` 不得翻译或拆开。  
- 危险操作（YOLO / 移除项目）两种语言都要写清后果。

## 验收清单（PR / Agent 自检）

- [ ] `MessageKey` 能约束所有 `t()` 调用（TypeScript 通过）。  
- [ ] `en` / `zh` 键集合一致（可用测试或脚本 diff）。  
- [ ] 设置切换语言后主界面文案立即变化。  
- [ ] 设置切换语言后 **托盘 / 状态栏菜单** 同步（`tray_i18n` + `tray_refresh`）。  
- [ ] 无新增裸露中文/英文用户文案（允许代码注释、日志、品牌专名）。  
- [ ] 改 `tray.*` 时同步改 `src-tauri/src/tray_i18n.rs`（原生菜单无法读 TS catalog）。

## 与其它 Agent

接手本仓库时：

1. 先读本文件与 `docs/llm-wiki/README.md`。  
2. 任何 UI 改动同步更新 `messages.ts` 双语。  
3. 若引入第三语言：扩展 `Locale`、补全 catalog，并更新本规则。

# Grok App · P0 / P1 能力矩阵

> 与 [`项目需求.md`](./项目需求.md) 同步。  
> **P0** = 对外宣称「日用就绪」门槛（**全部**勾选；**条目不删**）。  
> **Dogfood** = 内部日用可先按 Launch-Core 子集（见 [`AUTOPLAN-实施规格.md`](./AUTOPLAN-实施规格.md) §19），不降低公开门槛。  
> **P1** = 设计期预留入口，可灰显「即将推出」，不阻塞 MVP。  
> 验收时：每行填 `PASS` / `FAIL` / `N/A`，并附证据（截图路径 / 日志 / 测试名）。  
> 交互冻结（权限栈 / 输入矩阵 / session scope）：§17 · 工程契约：§18。

**决策锚点：** D1 指挥台优先 · D2 默认独立会话 · D3 不内嵌 CLI · D4 mac+Win · D5 三入口 · D6 MIT 非官方 · D7 默认审批（UI：Ask / once / session / Deny）。
